# OmniHunter

Always-on, compliance-first acquisition intelligence for residential, commercial, and operating-business deals that can be structured with seller financing, subject-to financing, assumable debt, master leases, lease options, seller carrybacks, equity partners, or other low-cash-to-close structures.

> Status: initial build scaffold. No listing or financing result is a guarantee. Every candidate requires independent title, legal, lender, insurance, tax, environmental, property-condition, rent, and operating due diligence before an offer or closing.
